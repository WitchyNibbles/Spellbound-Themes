# WitchyNibbles Spellbound Themes 2.0.0

Spellbound Themes 2.0 shares the palette of the [Moonlit Candle](https://github.com/WitchyNibbles/moonlit-candle) terminal theme (witchyterm) and redraws the file icons and the workbench's product icons.

- **New: WitchyNibbles Moonlit Candle**, first in the theme list: candle gold for what is active, pink for what needs you, lavender for keywords and focus, on a deep moonlit night.
- **Terminal parity:** Moonlit Candle and Moonlit give the integrated terminal witchyterm's Windows Terminal scheme: the background, foreground, cursor, selection and all 16 ANSI colours. VS Code lightens text it finds too dim; for colours that match Windows Terminal exactly, set `"terminal.integrated.minimumContrastRatio": 1` ([the README explains why](https://github.com/WitchyNibbles/Spellbound-Themes#the-terminal)).
- **Product icons redrawn** in one style, for every icon of a normal VS Code 1.141 session.
- **File icons redrawn** as small objects coloured by category, with badged folders, in dark, light and high-contrast sets. They are original drawings: they echo a language's name, never its logo.
- **Typography:** only keywords are bold, and not the ones the grammars mark as operators (such as `typeof` and `in`); comments, documentation and storage modifiers are italic.

**Upgrading from 1.x:** the themes look different (Moonlit, Daydream and Coven Contrast lose most of their bold, operators included; in Moonlit, added files and added lines are mint and warnings amber), twelve product icon keys are dropped and fall back to VS Code's own icons, and every file icon changes. The [CHANGELOG](https://github.com/WitchyNibbles/Spellbound-Themes/blob/main/CHANGELOG.md) lists every change. To stay on 1.2.1, use **Install Another Version...** in the Extensions view (and turn off **Auto Update** for the extension), or the VSIX of [v1.2.1](https://github.com/WitchyNibbles/Spellbound-Themes/releases/tag/v1.2.1).

Manual installation: download the VSIX below, then choose **Extensions: Install from VSIX...** in VS Code.
