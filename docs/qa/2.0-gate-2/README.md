- Fixes made while running:
  - Run 2026-10-10T10-28-47 stopped at main 125%, scm-conflict: `Timed out waiting for … .codicon-git-branch-conflicts`. Cause: Windows git, whose default is `core.autocrlf true`, wrote README.md back with CRLF on the 100% pass's `merge --abort`. The 125% launch restored the LF original from the pristine copy, but the index still held the CRLF file's size, so git took README.md for a local change and refused the merge ("Your local changes to the following files would be overwritten by merge: README.md"). Fix: `run-gate.mjs` sets `core.autocrlf false` in the fixture repository. Test: "the fixture keeps LF line endings, so a merge abort does not dirty README.md for the next scale". Reproduced and fixed against Windows git in a scratch repository, then checked in a two-scale run of the SCM scenes (2026-10-10T10-37-20, 48 captures, 0 warnings).
  - Run 2026-10-10T10-38-44 stopped at main 200%, terminal: `Timed out waiting for … terminal-decoration-success … terminal-decoration-error`. Cause: the unmaximized panel holds about 7 terminal rows at 200% (10 at 150%), so both decorated commands scrolled out of the viewport. At 150% that run's capture showed the failing command only in the sticky-scroll header, with no decoration. Fix: the terminal scene maximizes the panel (`ctrl+alt+shift+m`) after opening the terminal and before typing, and its teardown restores the panel before closing it, because the icon-sheet scene toggles the same command. Test: "the gate 2 terminal scene maximizes the panel, so both decorated commands stay in the viewport at 200%". Checked in a 200%-only main pass (2026-10-10T10-52-12, 168 captures, 0 warnings) before the gate run. main-terminal-panel is therefore taller than at gate 1.
